# Vibe Memory — Project Intelligence

View or record project memory — decisions, patterns, gotchas and preferences.

## To View Memory
Call `vibe_memory_show` with type="all" (or specific type) to see what's been learned about this project.

## To Record Memory
Call `vibe_memory_record` with:
- type="decision" — architectural or technical choices made
- type="pattern" — recurring code patterns to follow
- type="gotcha" — traps, bugs, or non-obvious behaviors to avoid
- type="preference" — user/team preferences about how things should be done

## Memory is used to:
- Avoid repeating past mistakes
- Enforce consistent patterns
- Carry context between sessions
- Build institutional knowledge
