# Vibe Mission — Start or Check Mission

Start a new development mission or check the status of the current one.

## To Start a New Mission
Describe what you want to build or accomplish. VibeAuryon will:
1. Break it down into concrete tasks
2. Identify which VibeAuryon tools are needed
3. Define the done criteria
4. Track progress through completion

## To Check Current Mission Status
Summarize:
- What was planned
- What's been completed
- What's blocked and why
- What's next

## Mission Lifecycle
```
draft → active → [blocked?] → completed
```

Each mission produces:
- Task list with checkboxes
- Evidence of completion per task
- Final debrief summary
