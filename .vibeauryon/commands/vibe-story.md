# Vibe Story — Create Development Story

Create a well-structured development story ready for implementation.

## Steps

1. **Understand the context**: Read the current project structure and any existing epics/stories
2. **Draft the story** using this template:

```
## Story: [Title]

**As a** [user type]
**I want** [feature/action]
**So that** [benefit/value]

## Acceptance Criteria
- [ ] AC-1: [specific, testable criterion]
- [ ] AC-2: [specific, testable criterion]
- [ ] AC-3: [specific, testable criterion]

## Technical Notes
- Files to create/modify:
- Dependencies needed:
- Edge cases to handle:

## Definition of Done
- [ ] Code implemented
- [ ] TypeScript errors: 0
- [ ] No console.logs left
- [ ] Tested manually
```

3. **Validate** the story has clear, testable acceptance criteria before starting implementation
